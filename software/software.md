## Installation

### Step 1: Update the Raspberry Pi

```bash
sudo apt update
sudo apt install full-upgrade -y
sudo reboot now
```

### Step 2: Install the VPTP software

```bash
chmod +x ./vptp_installer
./vptp_installer
```
